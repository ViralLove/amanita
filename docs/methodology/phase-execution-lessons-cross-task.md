# Буфер уроков выполнения фаз

**Роль:** временное накопление пунктов из раздела «Уроки для следующих фаз» ретроспектив по процессу. Не хранилище — уроки переносятся в методику, буфер затем очищается.

**Как использовать**
1. При выполнении фазы по run-phase после создания ретроспективы по процессу добавить сюда пункты из «Уроки для следующих фаз» (кратко, с указанием источника: фаза N, задача).
2. Периодически интегрировать накопленное в **docs/methodology/multi-step-phase-execution.md**, раздел **1.1 «Накопленные уроки»**.
3. После интеграции очистить этот файл, оставив только настоящее описание (роль + как использовать).

**Где живут уроки:** в методике (multi-step-phase-execution.md, п. 1.1). Этот файл — только буфер для переноса.
