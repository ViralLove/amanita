# Governance Architecture для AMANITA Ecosystem

## 🎯 Обзор системы управления

Архитектура governance для AMANITA, основанная на принципах кооперации и коллаборации между селлерами, с использованием трех токенов:
- **$LOVECOIN** - социальный майнинг через суперлайки
- **$AMANITA** - лоялти программы от селлеров к аудитории  
- **$TRUST** - governance токен (только через эмиссию, покупка запрещена)

## 📊 Стратегия сбора данных для эмпирического анализа

### 🎯 Принцип подхода
Вместо предварительного определения формул веса голоса, мы собираем максимальное количество релевантных метрик для последующего эмпирического анализа. Это позволит на основе реальных данных пользователей выявить корреляции между поведением и ценностью для экосистемы.

---

## 🔍 Анализ существующих метрик в экосистеме

### ⚙️ **SpiralEngine метрики**

#### Социальный капитал:
- `usedInviteByUser` - кто кого активировал
- `userActivator` - кто активатор пользователя
- `activatedBy[]` - кого активировал пользователь
- `nominatedSellers[]` - кого назначил селлером
- `inviteTransferHistory[]` - история владения инвайтами
- `userInviteCount` - количество созданных инвайтов
- `totalInvitesUsed` - общий уровень активации

#### Репутация и санкции:
- `violationCount` - количество нарушений
- `suspensionUntil` - время блокировки
- `activationViolations` - нарушения активированных
- `nominationViolations` - нарушения номинированных

### 💕 **LoveDoPostNFT метрики**

#### Социальная активность:
- `postsMintedBy` - количество созданных постов
- `postsPerUserPerMonth` - активность по месяцам
- `superlikedPostsByUser[]` - какие посты лайкал
- `monthlyLikesUsed` - суперлайки по месяцам

#### Качество контента:
- `superlikes` - количество суперлайков на пост
- `hasSuperliked` - кто лайкал посты
- `mentionsOf` - сколько раз упоминался селлер

### 🛍️ **ProductRegistry метрики**

#### Экономическая активность:
- `catalogVersion` - версии каталогов
- `productsBySeller[]` - количество товаров
- `activeProductIds[]` - активные товары

### 💰 **LoveEmissionEngine метрики**

#### Токеномическая активность:
- `loveAccrued` - накопленные Lovecoin
- `lgovAccrued` - накопленные LGOV
- `lgovClaimed` - статус клейма (текущее on-chain поведение на 2026-03-12: одноразовый `claimLGOV`, описание целевой модели см. таск `task-fix-loveemission-lgov-continuous-governance`)

## 🎯 Предлагаемые параметры для сбора

### 1. **Социальная ценность (Social Value)**

```solidity
struct SocialMetrics {
    uint256 activationDepth;        // Глубина в спирали (уровень)
    uint256 networkSize;            // Размер сети (количество активированных)
    uint256 networkQuality;         // Качество сети (репутация активированных)
    uint256 crossCategoryConnections; // Межкатегорийные связи
    uint256 mentorshipScore;        // Наставничество (качество активаций)
}
```

**Метрики для анализа:**
- Глубина активации в спиральной иерархии
- Количество успешно активированных пользователей
- Средняя репутация активированных пользователей
- Количество связей с другими категориями товаров
- Процент успешных активаций (без нарушений)

### 2. **Экономическая ценность (Economic Value)**

```solidity
struct EconomicMetrics {
    uint256 totalSales;             // Общие продажи
    uint256 crossSellerReferrals;   // Рефералы между селлерами
    uint256 loyaltyProgramsCreated; // Созданные лоялти программы
    uint256 customerRetentionRate;  // Удержание клиентов
    uint256 priceStability;         // Стабильность цен
}
```

**Метрики для анализа:**
- Объем продаж в токенах экосистемы
- Количество рефералов между селлерами
- Количество активных лоялти программ
- Процент возвращающихся клиентов
- Волатильность цен на товары

### 3. **Контентная ценность (Content Value)**

```solidity
struct ContentMetrics {
    uint256 postQualityScore;       // Качество постов (суперлайки/посты)
    uint256 engagementRate;         // Вовлеченность (лайки/просмотры)
    uint256 educationalValue;       // Образовательная ценность
    uint256 authenticityScore;      // Аутентичность (отсутствие спама)
    uint256 communityBuilding;      // Строительство сообщества
}
```

**Метрики для анализа:**
- Среднее количество суперлайков на пост
- Вовлеченность аудитории в посты
- Образовательная ценность контента
- Отсутствие спама и низкокачественного контента
- Вклад в развитие сообщества

### 4. **Репутационная ценность (Reputation Value)**

```solidity
struct ReputationMetrics {
    uint256 violationFreeTime;      // Время без нарушений
    uint256 disputeResolution;      // Разрешение споров
    uint256 communityTrust;         // Доверие сообщества
    uint256 consistencyScore;       // Постоянство качества
    uint256 longTermCommitment;     // Долгосрочная приверженность
}
```

**Метрики для анализа:**
- Время без нарушений в экосистеме
- Успешность разрешения споров
- Доверие других участников (отзывы, рейтинги)
- Постоянство качества товаров и услуг
- Длительность участия в экосистеме

### 5. **Инновационная ценность (Innovation Value)**

```solidity
struct InnovationMetrics {
    uint256 newProductLaunches;     // Запуск новых продуктов
    uint256 categoryExpansion;      // Расширение в новые категории
    uint256 processImprovements;    // Улучшение процессов
    uint256 knowledgeSharing;       // Обмен знаниями
    uint256 ecosystemContribution;  // Вклад в экосистему
}
```

**Метрики для анализа:**
- Количество новых продуктов
- Расширение в новые категории товаров
- Предложения по улучшению процессов
- Активность в обмене знаниями
- Вклад в развитие экосистемы

## 🔄 Вопросы для эмпирического анализа

### 1. **Корреляционный анализ**
- Какие метрики коррелируют с реальной ценностью для экосистемы?
- Есть ли скрытые паттерны в поведении успешных участников?
- Какие комбинации метрик дают лучший предиктивный результат?

### 2. **Временной анализ**
- Как изменяется ценность участников со временем?
- Какие метрики показывают долгосрочную приверженность?
- Есть ли сезонные паттерны в активности?

### 3. **Категорийный анализ**
- Различаются ли метрики ценности для разных категорий товаров?
- Какие метрики важны для нутрицевтиков vs косметики vs экотоваров?
- Есть ли универсальные метрики для всех категорий?

### 4. **Поведенческий анализ**
- Как поведение влияет на успех в экосистеме?
- Какие действия приводят к росту репутации?
- Как избежать гейминга системы?

## 🎯 Критерии качества метрик

### ✅ **Хорошие метрики:**
- **Измеримые** - можно точно подсчитать
- **Релевантные** - отражают реальную ценность
- **Стабильные** - не меняются кардинально со временем
- **Негеймируемые** - сложно подделать
- **Справедливые** - доступны всем участникам

### ❌ **Плохие метрики:**
- **Количественные без качества** - только объем без смысла
- **Легко подделываемые** - можно накрутить
- **Несправедливые** - доступны только избранным
- **Нестабильные** - сильно меняются без причины
- **Нерелевантные** - не отражают реальную ценность
