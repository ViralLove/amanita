1) Вход (Social Redirect)

Этот режим делает редирект на провайдера и возвращает на redirectUrl, где мы завершаем логин. (Нужно добавить callback URL в настройках Dynamic/провайдера.)

2) Подключить внешний кошелёк (EVM/Solana)

Мы строим список доступных wallet-провайдеров (MetaMask/Phantom и т.д.) и делаем connect+verify. 
{ "wallets": [] }

3) Сессия / JWT

user: unknown jwt: unknown 
{}
В JS SDK user доступен через dynamicClient.user, а токен — dynamicClient.token.

4) Примечания по embedded wallet (WaaS)

  • Если включите embedded wallet — обязательно дайте пользователю “Export key” поток.
  • Экспорт отображается в защищённом sandboxed iframe, который вы не контролируете.
  • Это удобно для вашей модели “самокастодиальность по запросу”: пользователь может мигрировать куда угодно.
(Экспорт/импорт ключей описан в docs Dynamic про embedded wallets / MPC.)
