# Plan for ItemY3: Исправление CSS классов и селектора .view:not(.hidden)

## 🎯 Цель
Исправить приоритет CSS правила `.hidden` над inline стилями и обеспечить корректную работу селектора `.view:not(.hidden)`.

## 🔍 Анализ проблемы
**Текущая ситуация**:
- CSS правило `.hidden { display: none !important; }` добавлено
- HTML структура исправлена (`success-screen` имеет класс `hidden`)
- НО: Inline стили все еще имеют приоритет над CSS классами
- Результат: Селектор `.view:not(.hidden)` находит `success-screen` вместо реально видимого экрана

## 🔧 План изменений

### Шаг 1: Исправление CSS приоритета
**Проблема**: Inline стили переопределяют CSS классы
**Решение**: Удалить inline стили из `switchView()`, оставить только управление CSS классами

### Шаг 2: Оптимизация функции switchView()
```javascript
// Было - конфликт между классами и inline стилями
el.classList.add('hidden');
el.style.display = 'none'; // ← конфликт!

// Стало - только CSS классы
el.classList.add('hidden');
// inline стили удалены
```

### Шаг 3: Добавление утилиты для определения видимого экрана
```javascript
function getVisibleView() {
  return document.querySelector('.view:not(.hidden)');
}
```
