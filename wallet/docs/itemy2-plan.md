# Plan for ItemY2: Исправление проблем с переключением экранов

## 🎯 Цель
Исправить функцию `switchView()` и CSS стили для корректного переключения экранов.

## 🔧 План изменений

### Шаг 1: Добавление CSS правила для .hidden
**Файл**: `styles.css`
```css
.hidden {
  display: none !important;
}
```

### Шаг 2: Исправление HTML структуры
**Файл**: `index.html`
- Добавить класс `hidden` к `success-screen`

### Шаг 3: Рефакторинг функции switchView()
**Файл**: `main.js`
1. **Удалить дублирование** в массиве `all`
2. **Изменить логику** для работы с CSS классами:
   ```javascript
   // Вместо inline стилей
   el.style.display = 'none';
   
   // Использовать CSS классы
   el.classList.add('hidden');
   el.classList.remove('hidden');
   ```

### Шаг 4: Синхронизация стилей
- Убедиться, что CSS классы и inline стили работают согласованно
- Добавить fallback для случаев, когда CSS не загружен

## 🛡️ Безопасность изменений
- **Поэтапное внедрение**: CSS → HTML → JavaScript
- **Обратная совместимость**: Сохранение inline стилей как fallback
- **Тестирование**: Проверка каждого экрана отдельно
- **Откат**: Возможность вернуться к предыдущему состоянию
