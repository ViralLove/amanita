Опции traceback:
--tb=short   # Короткий traceback (рекомендуется)
--tb=long    # Полный traceback (для детальной отладки)
--tb=line    # Только строка с ошибкой (минимальный вывод)
--tb=no      # Без traceback (только статус)

Для одного упавшего теста:
python3 -m pytest tests/unit/test_organic_components.py::TestComponentExists::test_returns_true_for_existing_component -v -s

Опция -s показывает print() output во время теста
