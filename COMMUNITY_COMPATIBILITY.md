Amanita Network — Community Compatibility Rules

This document defines the requirements for participation in the shared Amanita interoperability layer.

Local deployments are free to:

* Use their own branding
* Deploy independent smart contracts
* Customize user interfaces

However, to participate in shared interoperability (LOVE token economy, cross-community exchange, shared discovery, reputation graph), a deployment MUST comply with the following rules:

1. Protocol Identity

* The application must clearly indicate connection to the Amanita protocol
* Concealing protocol identity is not allowed

2. No Manipulative Marketing

* No paid ranking, boosting, or sponsored visibility
* No artificial promotion mechanisms

3. Honest Representation

* Must not misrepresent itself as the official Amanita network
* Must not mislead users about network participation status

4. Economic Integrity

* Must support shared interoperability rules (LOVE-based exchange)
* Must honor cross-community redemption commitments

5. Reputation Compatibility

* Must integrate with the shared reputation and feedback system
* Must not manipulate or fabricate reputation data

Violations result in:

* Loss of interoperability status
* Exclusion from shared discovery
* Disconnection from cross-community economy

Such deployments may continue to operate independently but will be treated as isolated systems.
