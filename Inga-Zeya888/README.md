# ReplaceOps Landing Page

Современный лендинг для B2B-платформы автоматизации бизнес-процессов с помощью LLM-агентов.

## 🎨 Дизайн-концепция

Лендинг реализует концепцию "handdrawn LED style" с неоновыми эффектами и технологической эстетикой:

- **Цветовая схема**: Глубокий ночной синий (#0c1524) с неоновыми акцентами
- **Стиль**: Минималистичный, технологичный, с элементами киберпанка
- **Анимации**: Плавные переходы, пульсация иконок, эффекты свечения
- **Адаптивность**: Полная поддержка мобильных устройств

## 🚀 Особенности

### Визуальные эффекты
- Неоновое свечение элементов
- Пульсирующие иконки
- Glitch эффекты для заголовков
- Параллакс эффекты
- Частицы в фоне
- Fade-in анимации при скролле

### Интерактивность
- Hover эффекты с трансформациями
- Плавная прокрутка
- Анимации при загрузке
- Эффекты при фокусе

### SEO и доступность
- Структурированные данные (JSON-LD)
- Семантическая разметка
- Поддержка клавиатурной навигации
- Оптимизация для поисковых систем

## 🛠 Технические требования

- Современный браузер с поддержкой CSS Grid, Flexbox
- JavaScript ES6+
- Поддержка Intersection Observer API
- WebGL для частиц (опционально)

## 📱 Адаптивность

Лендинг полностью адаптивен и оптимизирован для:
- Десктоп (1200px+)
- Планшет (768px - 1199px)
- Мобильный (до 767px)

## 🎨 Кастомизация

### Цветовая схема
Основные цвета определены в CSS переменных:
```css
:root {
  --bg-primary: #0c1524;
  --accent-green: #24c48e;
  --accent-cyan: #00ffff;
  --neon-glow: 0 0 20px rgba(0, 255, 255, 0.6);
}
```

### Анимации
Все анимации можно настроить через CSS:
- Скорость пульсации иконок
- Интенсивность неонового свечения
- Время fade-in эффектов

## 🚀 Развертывание

1. Скопируйте все файлы в корневую директорию веб-сервера
2. Убедитесь, что все пути к файлам корректны
3. Проверьте загрузку шрифтов IBM Plex Sans
4. Протестируйте на различных устройствах
